# EdTech Podcasts Page Documentation

## Overview

The EdTech Podcasts page (`/podcasts/`) displays a curated list of recent podcast episodes related to educational technology. The page is automatically updated daily at 4:00 AM EST using a GitHub Actions workflow that fetches episodes from the iTunes Search API and uses AI to select the most relevant ones.

## How It Works

### Architecture

1. **Automated Workflow**: A GitHub Actions workflow runs daily at 4:00 AM EST
2. **Data Fetching**: The script queries the iTunes Search API for recent EdTech podcast episodes
3. **AI Selection**: Replicate's Deepseek R1 model selects the most relevant episodes
4. **Static Output**: Selected episodes are written to `_includes/edtech-podcasts.md`
5. **Page Rendering**: The Jekyll site renders the markdown file as HTML

### Key Files

- **Page Template**: `podcasts.html` - The Jekyll page template
- **Content Include**: `_includes/edtech-podcasts.md` - The cached markdown file with episodes
- **Script**: `scripts/edtech_podcast_agent.py` - The Python script that fetches and selects episodes
- **Workflow**: `.github/workflows/update-edtech-podcasts.yml` - The automated GitHub Actions workflow

## Automated Updates

### Schedule

The workflow runs **daily at 4:00 AM EST** (9:00 AM UTC). This ensures fresh content every day without requiring manual intervention.

### Workflow Steps

1. Checks out the repository
2. Sets up Python 3.11 environment
3. Installs dependencies from `scripts/requirements.txt`
4. Runs `edtech_podcast_agent.py` with Replicate API token
5. Commits changes to `_includes/edtech-podcasts.md` if updates are found
6. Triggers GitHub Pages rebuild to deploy changes

### Manual Trigger

You can manually trigger the workflow from the GitHub Actions tab:
1. Go to `.github/workflows/update-edtech-podcasts.yml` in GitHub
2. Click "Run workflow" → "Run workflow"

## Script Configuration

### Default Settings

The script uses the following configuration (defined in `edtech_podcast_agent.py`):

```python
config = {
    'model': 'deepseek-ai/deepseek-r1',
    'keywords': [
        'edtech',
        'education technology',
        'higher education',
        'learning technology'
    ],
    'searches_per_keyword': 5,
    'max_candidates': 15,
    'max_selected': 10
}
```

### Search Parameters

- **Keywords**: Search terms used to find relevant episodes
- **Searches per keyword**: Number of API calls per keyword (default: 5)
- **Max candidates**: Top episodes considered for selection (default: 15)
- **Max selected**: Final number of episodes displayed (default: 10)
- **Date filter**: Only episodes from the last 30 days are included

### API Rate Limiting

The script respects iTunes API rate limits:
- 20 requests per minute
- 3.5 second delay between requests
- Automatic deduplication by episode ID

## Selection Criteria

The AI model (Deepseek R1) selects episodes based on:

### Priority Topics
- AI/ML applications in education (ChatGPT, AI tutoring, adaptive learning)
- EdTech innovation (digital learning platforms, educational software, VR/AR)
- Technology's impact on teaching/learning outcomes
- Education technology policy and funding
- EdTech market developments (M&A, funding, startups)
- Higher education technology trends
- Learning technology innovations

### Rejection Criteria
- Episodes not primarily about education technology
- Promotional content or ads
- Unrelated topics (general business, non-edtech startups)
- Duplicates or very similar episodes

## Manual Execution

To run the script locally:

### Prerequisites

1. Python 3.11+
2. Install dependencies:
   ```bash
   pip install -r scripts/requirements.txt
   ```
3. Set environment variable:
   ```bash
   export REPLICATE_API_TOKEN="your-token-here"
   ```

### Running the Script

```bash
cd scripts
python edtech_podcast_agent.py
```

The script will:
1. Fetch episodes from iTunes API
2. Select top episodes using AI
3. Update `_includes/edtech-podcasts.md`

### Output Format

The script generates markdown in this format:

```markdown
# EdTech Podcast Episodes
*Updated: November 20, 2025*

- 2025-11-18: [Episode Title](https://podcasts.apple.com/...) - from **Podcast Name** by Artist Name, November 18, 2025, 45m

  Episode description here...
```

## Performance

### Caching Strategy

The page uses **static file caching**:
- Episodes are fetched once daily via GitHub Actions
- Results are stored in `_includes/edtech-podcasts.md`
- Page loads instantly (no API calls on page load)
- JavaScript is deferred to prevent blocking

### Load Time

- **Server response**: ~0.026 seconds
- **No external API calls** on page load
- **Static content** served from GitHub Pages CDN

## Troubleshooting

### Episodes Not Updating

1. **Check workflow status**: Go to GitHub Actions → "Update EdTech Podcasts"
2. **Verify API token**: Ensure `REPLICATE_API_TOKEN` is set in repository secrets
3. **Check script output**: Review workflow logs for errors
4. **Manual trigger**: Try running the workflow manually

### No Episodes Found

1. **Check date filter**: Script only includes episodes from last 30 days
2. **Verify keywords**: Ensure search terms are relevant
3. **API issues**: Check if iTunes API is accessible
4. **Rate limiting**: Script includes delays, but API may still throttle

### Page Load Issues

1. **Clear browser cache**: Hard refresh (Ctrl+Shift+R / Cmd+Shift+R)
2. **Check GitHub Pages**: Verify site is building successfully
3. **JavaScript**: Scripts are deferred, shouldn't block rendering

### Script Errors

Common issues:
- **Missing dependencies**: Run `pip install -r scripts/requirements.txt`
- **API token**: Ensure `REPLICATE_API_TOKEN` environment variable is set
- **Network issues**: Check internet connection for API calls
- **Rate limiting**: Reduce `searches_per_keyword` if hitting limits

## Customization

### Changing Update Frequency

Edit `.github/workflows/update-edtech-podcasts.yml`:

```yaml
schedule:
  - cron: '0 9 * * *'  # Daily at 9:00 AM UTC (4:00 AM EST)
  # Change to weekly: '0 9 * * 1' (Mondays)
  # Change to twice daily: '0 9,21 * * *' (9 AM and 9 PM UTC)
```

### Modifying Search Keywords

Edit `scripts/edtech_podcast_agent.py`:

```python
config = {
    'keywords': [
        'your',
        'custom',
        'keywords',
        'here'
    ],
    # ...
}
```

### Adjusting Selection Criteria

Edit the `selection_prompt` in `select_top_episodes()` function to change what the AI prioritizes.

### Changing Number of Episodes

Modify `max_selected` in the config:

```python
config = {
    'max_selected': 15  # Show 15 episodes instead of 10
}
```
